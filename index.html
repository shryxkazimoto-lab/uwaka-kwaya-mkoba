📖 Mwongozo wa Kusanidi Google Sheets (bonyeza kuona)

Hatua za Kuunganisha Google Sheets

  1. Fungua Google Sheets → Tengeneza spreadsheet mpya → Nakili Spreadsheet ID kutoka URL (sehemu kati ya /d/ na /edit).
  2. Katika spreadsheet hiyo, nenda Extensions → Apps Script.
  3. Futa code yote iliyopo, kisha nakili na ubandike code hii yote kutoka sehemu ya "Apps Script Code" hapa chini.
  4. Bonyeza Deploy → New deployment → Web app.
  5. Weka: Execute as: Me · Who has access: Anyone.
  6. Bonyeza Deploy → Nakili URL inayotolewa → Ibandike kwenye sehemu ya "Script URL" hapo juu.
  7. Bonyeza Hifadhi Mipangilio kisha Jaribu Muunganiko.

Kumbuka: Mara ya kwanza utaulizwa ruhusa — kubali yote (ni ya salama kwa sababu ni script yako mwenyewe).
